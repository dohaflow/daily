## 🚦 다이어트 주요 기능

1. **3초 신호등 식단 & 물 2L 트래커**
   - 아침, 점심, 저녁마다 **🟢 초록불(클린) / 🟡 노란불(보통) / 🔴 빨간불(과식)** 원터치 체크
   - 8잔(250ml x 8) 물 마시기 트래커로 하루 2L 수분 섭취 시 보너스 도토리 획득
   - 밤 10시 이후 **[🛡️ 오늘 밤 야식 완벽 참아냄!]** 버튼으로 +15 도토리 획득

2. **원터치 마이크로 해빗 운동**
   - 15분 산책, 계단 3층 오르기, 스쿼트 20개, 스트레칭 등 부담 없는 틈새 운동 원터치 체크

3. **미래 자아 타임머신**
   - **`[오늘] ➔ [+2주 (-1.4kg)] ➔ [+1달 (-3.2kg)] ➔ [+3달 (-6.5kg 👑)]`**
   - 타임머신 버튼을 누르면 미래 미니미의 턱선과 몸매가 실시간으로 갸름해지며 황금빛 오라와 궁전이 펼쳐집니다.

4. **🚨 긴급 야식·폭식 SOS 타임머신**
   - 야식 생각이 날 때 30초 쿨다운 타이머와 함께 내일 아침의 나를 미리 상상하고, 참아내면 도토리 10개 즉시 지급!

5. **💌 미래의 나로부터 온 편지함**
   - 30일 뒤, 90일 뒤의 날씬해진 미니미가 보낸 감동 편지와 선물 도토리 수령

## 🚀 실행 방법

### 방법 1. 간편 더블 클릭
* [start.bat](file:///c:/Users/Do/OneDrive/Desktop/daily/start.bat) 파일을 더블 클릭하면 자동으로 웹 브라우저가 실행됩니다.

```powershell

```

* [index.html](file:///c:/Users/Do/OneDrive/Desktop/daily/index.html) 파일을 웹 브라우저(크롬, 엣지 등)로 더블 클릭하여 즉시 실행할 수 있습니다.
